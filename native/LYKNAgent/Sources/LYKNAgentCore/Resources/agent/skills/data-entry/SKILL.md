# Data Entry

Purpose:
Enter, transfer, or update structured information in web applications
(spreadsheets, CRMs, admin panels, forms, documents).

When this skill should be used:
Tasks that move known data into a site: filling spreadsheets, updating
records, completing multi-field forms, transcribing lists.

Procedure:

1. Gather and normalize the source data before starting entry.
2. Map source fields to destination fields explicitly; do not guess mappings
   for ambiguous columns — ask if truly ambiguous.
3. Enter data in a consistent order; verify each important value landed
   (read the actual field/cell value).
4. For long entry tasks, verify in batches rather than assuming a run of
   actions all succeeded.
5. Do not overwrite existing data unless the task requires it; when updating,
   confirm you are editing the right record.
6. Saving/submitting into systems of record can be consequential — check the
   safety rules when the submission affects other people or is irreversible.

Cautions:

- Spreadsheet-like apps often need cell focus before typing; verify the
  active cell.
- Auto-format transformations (dates, numbers, leading zeros) can corrupt
  data — verify formatting after entry.
