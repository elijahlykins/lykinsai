# Scheduling

Purpose:
Manage calendar events, bookings, reservations, and appointments.

When this skill should be used:
Tasks involving creating, moving, or canceling events; booking flights,
hotels, restaurants, or services; checking availability.

Procedure:

1. Pin down the exact date and time, resolving relative phrases ("next
   Friday") against today's date, and note the timezone when it matters.
2. Check for conflicts or existing bookings before creating new ones.
3. Capture all details the user specified: attendees, location, duration,
   notes.
4. For bookings: compare options (time, price, cancellation policy) before
   selecting; fill all details up to the final confirmation.
5. Confirming a booking or sending invitations is consequential - obtain
   approval before the final step unless pre-approved.
6. Verify the event or booking actually appears after creation.

Cautions:

- Off-by-one date errors are the most common scheduling failure; re-verify
  the date shown by the site before confirming.
- Watch cancellation/refund policies on paid bookings.
