Chrome Live Feed

One-time setup so LYKN can read text from your active Chrome tab while Live Screen Watch is on. Nothing streams until watch is on.

Finish in Chrome (one time)
  1. In Chrome, turn on Developer mode (top-right).
  2. Click Load unpacked.
  3. In the file picker press ⌘⇧G (Go to Folder), paste (⌘V), press Return, then choose the save-to-lykn folder and click Select.
  4. You should see LYKN Chrome Live Feed in your extensions list.
The folder is not on your Desktop, it’s in a hidden Application Support directory. Use ⌘⇧G + paste, or click Show folder in Finder below.
