Chrome Live Feed

Lets LYKN read your active Chrome tab when Live Screen Watch is on. You stay in control — nothing streams until you turn watch on.

Finish in Chrome (one time)
  1. Chrome opened to Extensions — that’s the page with your installed add-ons.
  2. Turn on Developer mode (top-right toggle).
  3. Click Load unpacked.
  4. Select the folder we opened in Finder (path below — already copied).

When it’s loaded, leave this window open — it closes automatically once LYKN sees the feed.
