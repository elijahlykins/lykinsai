Let LYKN see your screen

When you ask about what's in front of you, LYKN reads the screen for feedback, notes, and answers. macOS asks you to allow this once.

Checking…

Turn on LYKN in the list that opens. If macOS asks to quit & reopen the app, do it. This walkthrough picks up where you left off.

Talk to LYKN

Voice mode and dictation let you speak instead of type. Allow the microphone so LYKN can hear you.

Checking…

You can always add this later in System Settings → Privacy & Security → Microphone.

Browser superpowers optional

Let LYKN pull live article text and YouTube transcripts straight from your active tab, past paywalls and bot blocks.

Allow JavaScript from Apple Events

  1. Chrome / Brave / Edge: menu → More Tools → Developer → "Allow JavaScript from Apple Events"
  2. Safari: Settings → Advanced → "Show features for web developers", then Develop → "Allow JavaScript from Apple Events"
