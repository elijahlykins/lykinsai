2 · Read your browser tab optional

To pull live article text and YouTube transcripts from your active tab (bypassing paywalls & bot blocks), enable "Allow JavaScript from Apple Events" in your browser:

  1. Chrome / Brave / Edge: menu → More Tools → Developer → enable "Allow JavaScript from Apple Events"
  2. Safari: Settings → Advanced → "Show features for web developers", then Develop menu → "Allow JavaScript from Apple Events"
